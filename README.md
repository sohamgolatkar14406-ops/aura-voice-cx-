1. Why did you choose your particular architecture and technology stack?
-> I chose Lovable AI to build the user interface of my Aura Voice CX application and Vapi AI to create and manage the voice assistant, Aria, for Aura Skincare. I connected the application to Vapi and tested that Aria could speak and respond to users through the browser. I chose this approach because it allowed me to build a voice-based customer support application using AI-assisted development tools without having to build the entire voice system from scratch. I am using GitHub to manage and share my project code. My next step is to implement and test the backend for order lookups and complete the post-call transcript and summary features.
2. What was the most difficult part of the assignment, and how did you solve it?
-> The most difficult part of the assignment was integrating the AI voice agent with my website. Although I successfully connected the voice agent to the website, it initially failed to respond and displayed an error. To solve this, I shared screenshots of the error with the AI coding assistant and tried different fixes. After around three or four attempts, the issue was resolved, and the voice agent started responding through the website.
3. If you had one more week to work on this, what would you improve first and why?
-> If I had one more week, I would add an AI chatbot to the website alongside the existing voice agent. Some customers may not feel comfortable speaking or sharing their voice, so the chatbot would allow them to type their questions and get help with their problems. This would give customers more flexibility and make the customer support experience more accessible and convenient.
4. If handling 1,000 conversations per day, what would need to change?
-> If my application had to handle 1,000 conversations per day, I would focus on improving its scalability, reliability, and performance. I would implement a proper backend to handle order lookups securely and connect it to a database instead of relying only on sample order data. I would also add error handling, monitoring, and logging to identify and resolve issues quickly. Finally, I would test the application under higher traffic and ensure that the voice agent and backend could handle multiple customer requests efficiently while protecting customer information.
